\sectiontitle{Problem and required achievement}
{\smallbody
The thesis workflow uses lattice Boltzmann analysis to evaluate airfoils and deep reinforcement learning to explore BP3333 geometry changes. The result set is scientifically useful but difficult to review interactively: geometry, aerodynamic coefficients, and spectral information must stay synchronized while unpublished data remain protected.
}

\begin{callout}
{\color{Navy}\bfseries\small Defined achievement}\par\vspace{1pt}
{\smallbody A secure web product in which a reviewer drags geometry parameters, sees the nearest verified database wing and its $C_l$, $C_d$, and first two frequency peaks of SPOD mode 1 update live, and releases to snap every control to that exact stored wing. The interface never predicts or interpolates aerodynamic values.}
\end{callout}

\sectiontitle{Why this is an engineering task}
{\smallbody
\begin{itemize}
  \item \textbf{Scientific consistency:} the wing and every displayed metric must originate from one admitted provenance row.
  \item \textbf{Interaction quality:} nearest-neighbor search must remain deterministic, fast, accessible, and stable during drag.
  \item \textbf{Publication safety:} W\&B credentials, local paths, artifacts, and unpublished raw metadata must never reach the browser.
  \item \textbf{Operational safety:} failed hourly refreshes must leave the previous verified deployment online.
\end{itemize}
}

\sectiontitle{Safety model}
{\smallbody
The selected hosting design is Cloudflare Pages protected by Cloudflare Access: default deny plus email-allowlisted one-time codes for reviewers. The browser Refresh control only cache-busts the deployed manifest; it cannot contact W\&B or start an export. Both HTML and JSON data assets sit behind the same Access policy.
}

\begin{callout}[colback=white]
{\smallbody\textbf{Repository boundary.} The thesis checkout remained a read-only scientific reference at commit \texttt{4936dea}; production code neither imports nor mutates it. All implementation lives in the separate private \texttt{AI-final-course} repository.}
\end{callout}

\sectiontitle{Data path and trust boundary}
{\smallbody
Approved W\&B runs $\rightarrow$ narrow Python \texttt{scan\_history} export $\rightarrow$ ordered admission checks $\rightarrow$ compatibility grouping $\rightarrow$ float32-vector deduplication $\rightarrow$ canonical JSON and SHA-256 $\rightarrow$ Vite build and secret/path scan $\rightarrow$ Cloudflare Pages + Access $\rightarrow$ Zod validation and Web Worker search in React.
}

\sectiontitle{Interaction contract}
{\smallbody
\begin{itemize}
  \item During pointer or keyboard drag, an animation-frame-throttled worker normalizes only variable parameters by authoritative BP3333 bounds and selects the exact nearest row.
  \item Ghost markers preserve requested positions; the wing, signed $C_l/C_d$ bars, frequencies, and provenance preview always change together.
  \item On release, all sliders animate to the selected database vector. Stable record index breaks equal-distance ties, preventing flicker.
  \item Refresh validates a new checksum and every shard before an atomic swap; unchanged, malformed, stale, offline, and empty states remain distinct.
\end{itemize}
}

\sectiontitle{Public data contract}
{\smallbody
The manifest reports generation time, run/sample/geometry counts, rejection totals, group descriptors, authoritative bounds, and chunk checksums. Compact columnar datasets retain full BP3333 vectors, raw per-wing $C_l/C_d$, ranked mode-1 peaks, curvature, minimal run/step provenance, and replicate counts; no 253-point coordinate arrays are stored per row.
}

\sectiontitle{Material human corrections}
{\smallbody
\begin{itemize}
  \item Rejected observed-range normalization: the nearest wing would change when sample coverage changed. Fixed authoritative BP3333 bounds now define distance.
  \item Corrected frequency semantics: the cards show two ranked frequency peaks of SPOD mode 1, not frequencies of SPOD modes 1 and 2.
  \item Removed an early per-row coordinate-array field; TypeScript reconstructs 253 geometry points from the ten parameters.
  \item Replaced an analytic reference curve with the exact BP3333 NACA2412 baseline; split unique-wing and successful-sample counts.
\end{itemize}
}

\sectiontitle{Agent split and evidence discipline}
{\smallbody
The lead established the immutable thesis boundary and integration contract. Independent data, frontend, and QA agents worked in parallel, followed by lead review. The portable project skills \texttt{curate-aero-wandb-data} and \texttt{verify-airfoil-explorer} encode future refresh and acceptance workflows. The evidence log records prompts, diffs, corrections, validation, and conservative time-saved estimates from the first implementation action.
}

\begin{callout}[colback=white]
{\smallbody\textbf{Observed value of the custom skill.} The major improvement was not writing speed; it was eliminating plausible scientific errors in field choice, normalization, frequency interpretation, grouping, and replicate provenance before they reached the interface.}
\end{callout}

\sectiontitle{Physical validity and limits}
{\smallbody
Admission requires a finished approved run, known absolute-action schema, bounded finite actions, finite raw step $C_l/C_d$, valid geometry, curvature ratio below one, and positive finite peaks when frequency coverage is declared. Incompatible baseline, AoA, averaging window, SPOD setup, or solver revision values never mix; unknown settings are isolated. Exact float32 vectors define unique geometries, while every valid replicate remains counted and traceable.

\textbf{The current public snapshot is deliberately synthetic:} 8 admitted samples and 7 geometries across five reviewed run identities. It proves the software contract, not thesis performance. No claim is made that the expected live sample count or production access controls have been verified.
}

\sectiontitle{Reflection}
{\smallbody
The most consequential design choice was to treat scientific validity as a data contract rather than a visual concern. AI produced substantial breadth quickly, but the reusable skill and review checkpoints prevented plausible-looking errors in key selection, distance normalization, frequency labeling, and provenance. Fail-closed behavior was also valuable: missing network or deployment authority produced explicit blockers instead of unreviewed data or invented evidence.
}
