# Acceptance checklist

- [ ] Every data chunk validates against its descriptor and checksum.
- [ ] Slider preview and release select exact saved records with stable ties.
- [ ] Visible geometry, `Cl`, `Cd`, and provenance agree on one record.
- [ ] Keyboard, touch, focus, reduced motion, desktop, and mobile layouts pass.
- [ ] Refresh is atomic and handles unchanged, newer, malformed, unavailable, and offline snapshots.
- [ ] Built assets contain no credentials, local paths, raw artifacts, W&B namespace, or undeclared research data.
