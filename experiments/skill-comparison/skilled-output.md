# Skilled response

## Prompt

> Build the W&B-to-dashboard data refresh and nearest-wing interaction while preserving scientific validity and protecting unpublished data.

## Proposed implementation

Treat publication as a registry-controlled data release. The reviewed registry contains only `fo7gm0ds`, `opffdpy8`, `5etm3jjj`, `nl9fb08e`, and `k202yi52` in entity `edenunu-technion-israel-institute-of-technology`, project `wing parameter test`. Audit `sjhhvgd6`, `elstxotw`, `1n93x16f`, `syqss1sr`, `ud0cqk5m`, and `y44fmpfc` separately, record stable exclusion outcomes, and never promote them automatically. A finished or plausible run is not publication approval.

The Python exporter uses W&B's server-side `scan_history` and requests only `_step`, the minimum timestamp, the ten `action/*` BP3333 keys, `aero/step_avg_Cl`, `aero/step_avg_Cd`, `geometry/step_curvature_ratio`, `status/invalid_geometry`, and the first two ranked peaks of SPOD mode 1: `spod/mode1_peak_freq_1` and `spod/mode1_peak_freq_2`. It does not fetch artifacts, media, models, full config or summary objects, system metrics, episode `avg_Cl`/`avg_Cd`, or arbitrary metadata. W&B access stays in the exporter; the static dashboard never receives credentials or calls W&B.

Validate public output with versioned Pydantic `SnapshotManifestV1`, `WingDatasetV1`, and `WingRecord` contracts. Admit a row only from a finished allowlisted run with a known absolute-action schema, finite in-bound present actions, finite per-wing `Cl` and `Cd`, numeric `invalid_geometry == 0`, and finite curvature ratio below one. If its registry entry declares frequency coverage, also require both SPOD mode-1 ranked peaks to be finite and positive. Count one primary rejection reason in the contract's exact precedence: `RUN_NOT_FINISHED`, `RUN_NOT_APPROVED`, `UNKNOWN_ACTION_SCHEMA`, `NONFINITE_ACTION`, `ACTION_OUT_OF_BOUNDS`, `MISSING_AERO`, `NONFINITE_AERO`, `INVALID_GEOMETRY`, `MISSING_VALIDITY`, `MISSING_CURVATURE`, `CURVATURE_LIMIT`, `MISSING_FREQUENCY`, `NONPOSITIVE_FREQUENCY`. No row disappears silently.

Reconstruct each full parameter vector independently from the pinned NACA2412 baseline, overwriting only absolute actions present in that row in this authoritative order: `r_le`, `x_c`, `y_c`, `k_c`, `y_t`, `x_t`, `beta_te`, `k_t`, `gamma_le`, `alpha_te`. Never carry a missing action forward from a preceding row. The compact public dataset emits that full vector rather than repeated coordinate arrays. The browser's BP3333 port reconstructs coordinates from it, and a checked-in golden fixture generated by the read-only authoritative implementation proves coordinate parity.

Compatibility identity is explicit and normalized across baseline, angle of attack, CFD averaging window, SPOD settings, and solver revision. An unknown value yields a run-isolated group rather than being mixed into a known group. Active parameters are derived per group from the admitted full vectors. The UI searches only inside one compatibility group and only over parameters that vary there. It normalizes with the authoritative BP3333 minimum/maximum bounds—not observed sample ranges—computes Euclidean distance, and resolves ties by the lowest stable record index. The chosen aerodynamic/frequency tuple always comes from one admitted representative; it is never interpolated or predicted.

Deduplicate by the exact bytes of the full float32 parameter vector. Preserve total admitted sample counts, select a representative by newest sanitized timestamp, then greatest global step, then lexicographically greatest run ID, and emit `replicateCount`. Minimal provenance is only run ID, global step, and normalized recorded time.

Write deterministic, canonical JSON shards below 10 MiB, hash each with SHA-256, verify every schema/checksum/size before atomic publication, and write the manifest last so a failed refresh cannot replace the prior snapshot. Scan built bytes for tokens, secret formats, home paths, hostnames, GPU telemetry, artifact names, and undeclared fields. Fixture mode must replay byte-identically when the controlled generation timestamp is fixed. Tests cover admission precedence and accounting, full-vector reconstruction, physical grouping and unknown isolation, float32 deduplication/representative choice, nearest-distance semantics, golden coordinates, checksums, file limits, secret scanning, and deterministic replay. Live export runs only if existing authentication works without revealing credentials; otherwise fixture export remains the explicit reproducible path and the live blocker is reported.
